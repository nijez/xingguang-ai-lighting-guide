# 馨光 AI 设计灯光安装指导

本教程用于内测。当前推荐方式是：腾讯云 OrcaTerm 免密终端安装基础环境，Lighthouse Agent 控制台对话页负责后续米家绑定、家庭选择和本地安装馨光 Skill。

对应腾讯云 2026 年 9 月新版控制台：服务器详情页「应用管理」只保留「Lighthouse Agent 控制台」入口；模型、通道、技能、对话全部迁移到 Agent 控制台；终端登录改为「登录」按钮 → OrcaTerm「免密连接（TAT）」。

第一阶段脚本版本：`2026-06-25.81`
第二阶段脚本版本：`2026-06-25.24`
维护面板版本：`1.2.8`
Skill 版本：`4.0.1`（官方原版）
Miloco：跟随官方 latest（2026-09-16 实测 2026.9.11）

## 内测流程

1. 创建腾讯云轻量服务器，选择龙虾（OpenClaw）应用模板。
2. 打开「Lighthouse Agent 控制台」→「设置」→「Agent 管理」，模型区域切换到深度求索（DeepSeek）并填入 API Key；需要微信控制的在「通道」区域授权接入微信。
3. 服务器详情页点「登录」→ OrcaTerm 登录框保持「免密连接（TAT）」→ 点「登录」→ 粘贴安装命令。
4. 看到「[100%] 基础环境安装完成」后，到 Agent 控制台「对话」页发送「绑定米家账号」，按链接授权并把授权码贴回。
5. 如果账号下有多个家庭，回复馨光设备所在家庭的序号。
6. 看到「下一步：请发送安装馨光 Skill」后，发送「安装馨光 Skill」。
7. 安装成功后，说灯光需求，并按现场情况回复“已变化”或“未变化”。

## 终端安装命令

```bash
curl -fsSL https://nijez.github.io/xingguang-ai-lighting-guide/install-xinguang-ai-light.sh -o install-xinguang-ai-light.sh && bash install-xinguang-ai-light.sh
```

如果终端窗口中断，重新点「登录」进入终端，运行：

```bash
bash install-xinguang-ai-light.sh status
```

## DeepSeek API Key

在 Agent 控制台的模型设置里填写一次即可，切勿粘贴到龙虾对话里。

获取 Key：https://platform.deepseek.com

## 龙虾后续操作

安装完成后，到 Agent 控制台「对话」页：

```text
绑定米家账号
```

绑定成功后，如果账号下有多个家庭，回复序号。家庭选择完成后，发送：

```text
安装馨光 Skill
```

## 灯光测试示例

```text
客厅来个马尔代夫的海边日落。
二楼客厅来一个森林晨光。
全屋灯带做一个朋友聚会氛围。
```

灯光请求发出后，龙虾会提示你观察现场。

- 如果已变化，回复：已变化
- 如果未变化，回复：未变化

测试成功后，如果当前效果满意，也可以说：保存当前灯光效果到快照 3。

## 维护面板

安装完成后，在终端输入 `xinguang` 可打开维护面板（体检 / 灯光测试 / 设备 / 切换家庭 / 更新组件）。

## 龙虾版本

龙虾（OpenClaw）保持腾讯云镜像自带版本，不要自行升级；如需升级只用 Agent 控制台「设置 → 实例运维 → 更新镜像」。

## 备用方式

如果必须在龙虾对话里尝试安装，可以使用页面里的备用方式。但如果龙虾提示无法执行脚本、要求查看脚本、反复解释风险，或中途切换成英文说明，请改用腾讯云免密终端安装。
