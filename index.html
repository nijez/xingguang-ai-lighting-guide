馨光 AI 设计灯光安装指导

安装交给腾讯云终端，对话交给龙虾，灯光设计交给馨光 Skill。

安装时请使用本页提供的命令。教程对应腾讯云 2026 年 9 月新版控制台（Lighthouse Agent 控制台 + OrcaTerm 免密终端）。
推荐方式：在腾讯云服务器页面右上角点击「登录」，在弹出的 OrcaTerm 登录框里保持默认的「免密连接（TAT）」，进入终端后粘贴安装命令。

项目目标

终端安装基础环境，并预置馨光 Skill 本地安装器。完成米家绑定和家庭选择后，在 Agent 控制台对话页发送「安装馨光 Skill」；安装成功后，你可以对龙虾说灯光需求，例如：“客厅来个马尔代夫的海边日落。”

灯光请求发出后，龙虾会让你现场确认灯光是否变化。

安装流程

1

准备龙虾服务器

创建腾讯云轻量服务器，选择龙虾（OpenClaw）应用模板。

2

配置 DeepSeek 模型

进入「Lighthouse Agent 控制台」→「设置」→「Agent 管理」，在模型区域切换到深度求索（DeepSeek）并填入 API Key。需要用微信聊天控制灯光的，在同一页的「通道」区域授权接入微信。

3

腾讯云免密终端安装

服务器页面点「登录」→ 登录框保持「免密连接（TAT）」→ 点「登录」→ 在终端粘贴本页安装命令。

4

在 Agent 控制台绑定米家账号

打开「Lighthouse Agent 控制台」的「对话」页，发送：绑定米家账号。龙虾给出授权链接后，点击完成授权，把授权码粘贴回来。

5

选择米家家庭

如果账号下有多个家庭，回复馨光设备所在家庭的序号。

6

安装馨光 Skill

看到「已切换到【家庭】，下一步请发送安装馨光 Skill」后，发送：安装馨光 Skill。

7

测试灯光效果

馨光 Skill 安装成功后，再说灯光需求，并按现场情况回复“已变化”或“未变化”。

准备龙虾服务器

购买腾讯云轻量应用服务器时，选择龙虾（OpenClaw）应用模板。服务器创建完成后，先配置 DeepSeek 模型，再进入免密终端安装。

购买腾讯云龙虾服务器

打开腾讯云活动页。

查看腾讯云 OpenClaw 实践教程

查看腾讯云官方实践教程。
新版控制台里，服务器详情页的「应用管理」只剩两个入口：「Lighthouse Agent 控制台」（模型、通道、技能、对话都在这里）和「安全访问 WebUI」。本教程只用前者。

配置 DeepSeek 模型（可选：接入微信）

在服务器详情页「应用管理」点「立即前往」，或左侧菜单点「Agent 控制台」，打开 Lighthouse Agent 控制台。点左上角「设置」→「Agent 管理」→「模型-通道-技能」：

  1. 在「模型 (Models)」区域找到「切换模型」，选择「深度求索（DeepSeek）」，填入 API Key。
  2. 模型选「DeepSeek V4.1 Flash」（按量付费、费用极低），点「切换为默认」。
  3. 需要在微信里和龙虾对话的，在「通道 (Channels)」区域选择「微信」，点「授权接入」，按提示扫码完成。不接微信也可以，直接用「对话」页控制灯光。
DeepSeek API Key 只需要在这里填写一次，切勿粘贴到龙虾对话里。

DeepSeek 开放平台 / 获取 API Key

注册后在控制台创建 API Key。
配置好后回到「对话」页，输入框右下角显示「DeepSeek …」即表示模型已生效。

推荐方式：腾讯云免密终端安装

回到服务器详情页，点右上角蓝色「登录」按钮。浏览器会打开 OrcaTerm 终端，并弹出「登录」对话框：

  1. 「连接协议」保持默认的「免密连接（TAT）」，用户名保持 ubuntu。
  2. 点蓝色「登录」按钮，等待几秒出现 ubuntu@VM-xxx:~$ 提示符。
  3. 把下面这条命令粘贴进终端，回车。
curl -fsSL https://nijez.github.io/xingguang-ai-lighting-guide/install-xinguang-ai-light.sh -o install-xinguang-ai-light.sh && bash install-xinguang-ai-light.sh

安装全程约 7 到 10 分钟，中间「正在安装灯光服务」会安静几分钟，属正常。看到「[100%] 基础环境安装完成」即可进入下一步。

如果终端窗口中断，重新点「登录」进入终端，运行状态查询命令。不要重复运行安装命令。

bash install-xinguang-ai-light.sh status
终端安装完成后，建议先到腾讯云「快照」页创建一次快照，后续需要回滚时更方便。
提示：龙虾（OpenClaw）请保持腾讯云镜像自带的版本，不要自行升级；如需升级，只用 Agent 控制台「设置 → 实例运维 → 更新镜像」。

绑定米家账号

打开 Lighthouse Agent 控制台的「对话」页（服务器详情页「应用管理」→「立即前往」，或左侧菜单「Agent 控制台」）。首次打开可能显示「正在检测实例连接状态」，等待约 1 分钟，左上角变成「运行中」后，直接发送：绑定米家账号。

绑定米家账号
  1. 龙虾给出「点击打开米家授权链接」。
  2. 点击链接打开米家授权页，用小米账号登录后点「确认授权」。
  3. 授权成功后点击「复制授权信息」。
  4. 回到对话页，把授权码粘贴发送。
  5. 看到「米家账号绑定成功」后，龙虾会列出家庭。
如果米家授权页打开后显示 “A server error occurred”，是小米账号服务临时故障，与你的服务器无关。等几十分钟后，重新发送「绑定米家账号」拿新链接再试。

选择米家家庭

如果你的米家账号下有多个家庭，龙虾会列出家庭并编号。直接回复馨光设备所在家庭的序号，例如 2。看到「已切换到【家庭名】。下一步：请发送「安装馨光 Skill」。」即完成。

绑定后 Miloco 可能会主动问“家里都有谁呀”之类的家庭信息，这是 Miloco 自带的家庭档案功能，与灯光无关，可以不理会或回复「跳过」。

安装馨光 Skill

家庭选择完成后，在同一个对话里发送：安装馨光 Skill。

安装馨光 Skill
安装成功后，龙虾会提示可以开始测试灯光。安装 Skill 后，如果龙虾对灯光需求没有反应，先发送 /new 开一个新会话再试。

测试灯光效果

馨光 Skill 安装成功后，再告诉龙虾想要的灯光效果。

和灯光对话的推荐说法

推荐句式：「<房间>淡彩光 <想要的感觉>」

例如：门市淡彩光 圣诞节、客厅淡彩光 马尔代夫的海边日落。

说「星光」也可以；语音输入把「馨光」听成「新光」或「心光」都能正常识别。

也可以直接描述想要的氛围，例如「客厅来个马尔代夫的海边日落」，同样有效。

客厅来个马尔代夫的海边日落。
二楼客厅来一个森林晨光。

龙虾发出灯光请求后，只需要现场观察灯光是否变化。

如果已变化，回复：已变化。如果未变化，回复：未变化。

测试成功后，如果当前效果满意，也可以说：保存当前灯光效果到快照 3。

常见问题

点「登录」后提示“登录失败 / 凭据错误”？

多见于服务器回滚过快照。在 OrcaTerm 左侧「连接管理器」里右键这台服务器 →「编辑」→ 连接协议改为「免密连接（TAT）」→「连接并保存」。

点「登录」提示“无法免密登录 / 自动化助手状态检测失败”？

服务器刚开机或刚回滚快照后 3 分钟内常见，是腾讯云侧状态还没同步。等 30 到 60 秒，刷新页面再点「登录」即可，不要改用密码登录。

终端安装卡住怎么办？

「正在安装灯光服务」安静几分钟属正常。如果超过 15 分钟没有新提示，运行终端状态查询命令；不要重复运行安装命令。

找不到以前的“模型设置 / 通道 / AgentChat”？

腾讯云已把这些功能迁移到「Lighthouse Agent 控制台」。服务器详情页「应用管理」→「立即前往」即可进入，对话页就是原来的 AgentChat。

Agent 控制台显示“未运行 / 正在检测实例连接状态”？

安装或重启后头一分钟常见。等待约 1 分钟后刷新页面，左上角变为「运行中」即可。

DeepSeek API Key 在哪里填写？

Agent 控制台 →「设置」→「Agent 管理」→ 模型区域「切换模型」→ 深度求索（DeepSeek）。填一次即可。

米家账号怎么绑定？

在 Agent 控制台对话页发送「绑定米家账号」，按授权链接完成授权，把授权码粘贴回对话。

有多个米家家庭怎么办？

回复馨光设备所在家庭的序号。以后要换家庭，在终端输入 xinguang 用维护面板「切换家庭」。

灯光未变化怎么办？

回复「未变化」。龙虾会提示测试未通过，请在终端输入 xinguang 跑一次「一键体检」，把结果发给工作人员。

龙虾（OpenClaw）要不要升级？

不要自行升级。控制台提示“镜像可更新”时，只用 Agent 控制台「设置 → 实例运维 → 更新镜像」，升级后在终端输入 xinguang 跑一次体检。
